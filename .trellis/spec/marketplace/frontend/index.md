# Marketplace Frontend Guidelines

> Marketplace has no frontend app. Frontend content is spec/skill guidance.

## Overview

The marketplace repository does not render UI. Frontend-related files are
downloadable guideline templates and skills about frontend development.

## Pre-Development Checklist

- Identify whether you are editing a skill or a spec template.
- For spec templates, read that template's `frontend/index.md` and
  `shared/index.md`.
- For skills, read `SKILL.md` frontmatter and linked references.
- Keep marketplace `index.json` in sync if adding or moving downloadable
  resources.

**Language**: English unless the template explicitly provides localized content.
